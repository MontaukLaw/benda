# 上位机基线与状态机实验

在传感器上位机右侧打开 **基线与状态机**，保持传感器释放，点击 **释放后重新初始化**。
初始化完成后点击 **查看实验波形**，现有波形区显示 input、baseline、Signal、压力变化速度及所选通道状态阶梯图。
波形顶部的 **波形来源** 可以切回固件上报；监控表的 State / Raw / K 标签也随来源明确改变。
在本页顶部或实验波形顶部选择 **实验观察通道**，input、baseline、Signal、压力变化速度、状态阶梯图和背景一起切换。
切换观察通道只改变显示，不重置算法或基线。观察通道会保存，下次启动恢复。
需要叠加多个通道时，可在监控页另行勾选曲线；再次切换观察通道则回到所选通道的单通道显示。
实验来源下，波形设置页的背景通道选择也会同步切换完整观察内容。
参数页不再放通道数据表；请到 **监控** 页查看各通道状态、input、baseline、Signal 和最近激活原因，波形来源选择上位机实验。

监控数据表最右侧的 **最近激活原因** 区分 idle 差值触发、slowback / recover 重新加载，以及负向下冲及其后续恢复超过原零点。
鼠标悬停可查看触发当帧的 input、baseline、差值与门限、阶段谷值、回升量、上升速度、卸载前参考基线及超出参考的余量和连续确认帧数。
原因在退出 activate 后仍保留，下一次激活更新；重新初始化清除。切换观察通道不会清除各通道的原因。
固件协议未上报激活原因，固件来源下此列显示 `--`。
历史列顺序配置自动兼容，新列追加到最右侧，也可通过数据列按钮隐藏或调整顺序。

这是显式的上位机实验模型，20 通道各有独立状态、窗口和计数，共用本页参数。
固件 Raw / Baseline / Signal / 状态不被改写；柱状图和触摸板可显式选择上位机 Signal，原阵列质心页保留其原有来源选择。
实验同时支持完整 Debug 和 Raw-only 上传；Run 没有 Raw 时停止并清空实验输出。

## 柱状图使用实验 Signal

在 **柱状图设置 → 数据来源** 选择 **上位机计算 Signal**，20 路柱体使用本状态机的 Signal：activate 为 `max(input − baseline, 0)`，其他状态为 0。
Signal 已含 Raw 增益、输入低通和基线处理，显示时不再乘一次增益。此选择独立于波形来源，不需要先切换实验波形。
三种来源各自保存高度上限，新来源默认 20000；支持自动量程、显示实际值、超量程裁剪柱高及鼠标旋转。来源、量程和视角自动保存，下次启动恢复。
需要完整 20 通道 Raw，初始化时显示 0 并提示保持释放；Run 未上传 Raw、采样中断、增益/参数重置或刚重连时清除旧柱体，等待新的实验输出，不使用旧 Signal 或固件 Signal 替代。

## 实验 Signal 驱动触摸板

在 **触摸板 → 触摸板输入来源** 选择 **上位机 Signal 质心**（新版本默认选择），勾选 **启用相对触摸板试验**。保持释放，等待本页的 baseline 初始化完成；无需另采集触摸板松手参考。
位置按全部 20 通道的非负 Signal 加权：`Cx = Σ(Signal[ch] × (ch // 4 + 0.5)) / ΣSignal`，`Cy = Σ(Signal[ch] × (ch % 4 + 0.5)) / ΣSignal`。
X 向右、Y 向下，单位为格；仅 activate 通道有正权重。Signal 已含增益、低通及基线处理，不再乘增益、减参考或添加通道中值滤波。
计算前必须至少存在一对 **上下左右相邻的 activate 通道**；仅1路、0路，或所有激活通道互不相邻时不计算质心。按4行5列的实际网格判断，CH0–CH1与CH0–CH4相邻，CH3–CH4及对角线CH0–CH5不相邻。
这个条件是计算门控，满足后仍用全部20路 Signal 加权，并非只选两路或最强局部区域。
相邻条件不满足时保留最后的滤波前后质心，界面标注“保持”，dx/dy为0；清空运动滤波和像素小数余量，不继续推进光标或表盘。条件恢复后重新确认接触，首帧锚定，不补发保持期间的坐标差。初始化、无效数据、来源切换和真正断流仍清除旧轨迹。
质心通过触摸板现有 One Euro 位置滤波，连续接触时用 `dx = (Cx_filtered[t] − Cx_filtered[t−1]) × 灵敏度` 和同式 dy 推进画布。界面同时显示滤波质心、格单位质心差及像素位移。
每个有效 Raw 采样先由实验状态机计算 Signal 与真实实验状态，再将同序号的结果交给触摸板；GUI 批次中间帧不会复用末帧权重或状态。日志以 `source=host_signal_centroid` 明确区分，并记录该帧 Signal、`host_state`、激活通道及相邻对、初始化代数和质心差；门控原因记为 `no_adjacent_activate_pair`，`centroid_held` 标记显示位置是否保持。
接触阈值、30 毫秒确认、整体卸载门控、跳变和断流重置均保留；首次落指和重置后只锚定，Signal 消失或整体卸载后不继续输出滤波尾量。整体卸载阈值使用触摸板设置，未采集 Raw 噪声时按每路 2 count 最小噪声门限判断。
输入来源、数值设置自动保存；启用与系统鼠标控制开关不跨启动保存。保留 **Raw 减松手参考** 模式供对比。来源、增益、基线重新初始化和硬件参数变化都会断开旧轨迹。
系统鼠标仍需明确勾选控制开关；圆形表盘直接接收同一质心差（格），再使用表盘独立灵敏度，不必开启系统鼠标。

## 计算定义

1. 每帧使用柱状图设置保存的 20 路 Raw 增益，先 `scaled_raw = raw × gain`，再 `input += input_alpha × (scaled_raw − input)`。
   第一帧以 scaled_raw 初始化低通，避免从零爬升。增益为 0 的通道停用，Signal 为 0，速度不计算。
2. 初始化按实际采样时间持续 3 秒，baseline 取该期间 **低通 input 的最大值**。此时 Signal 为 0，请全程保持释放。
3. 速度窗口在所有状态保留最近 20 个有效采样，用真实时间对 input 做线性回归，斜率单位 count/s。
   压力变化速度 `rate = 100 × slope / 当前 input`，单位 %/s；下降阈值填正数 20 表示 `rate <= −20`。
   仅 activate 向监控数值和波形输出速度；其他状态数值显示 `--`，曲线留空，不以 0 代替未输出值。
   idle 仅保留采样窗口，不做速度回归；达到激活确认的当帧计算速度，使 activate 首帧可以使用完整历史。
   slowback / recover 仍在内部计算判定速度，用于重新加载、暂停快速基线跟踪和恢复稳定性确认。
   若这些状态完全停止计算速度，现有的重新按压及恢复稳定性规则将无法成立。窗口未满或 input 小于归一化下限时速度无效。
   这是 Raw 相对变化率，不是经过力标定的物理压力变化率。
4. 激活判据是 `input − baseline > 激活差值`，不是原始 Raw 超过 200。

## 状态与默认值

| 状态 | 基线 | Signal | 转移条件 |
| --- | --- | --- | --- |
| idle | alpha 0.002 慢跟踪 | 0 | 差值 > 200 连续 3 帧 → activate；确认候选期间暂停跟踪 |
| activate | 冻结 | max(input − baseline, 0) | 速度 ≤ −20 %/s 连续 2 帧，或差值 < 50 连续 5 帧 → slowback |
| slowback | 冻结 | 0 | 最长保持 300 个有效采样帧，或相对基线差值 ≤ 10% 连续 3 帧 → recover |
| recover | alpha 0.1 快跟踪 | 0 | 基线差绝对值 ≤ 20 且速度绝对值 ≤ 2 %/s，连续 5 帧 → idle |

slowback / recover 都支持重新按压：速度 ≥ 20 %/s、较进入等待后的谷值增加 > 200、且 input − baseline > 200，连续 3 帧 → activate。
默认还须 `input > 卸载前参考基线 + 300`，余量可在“重新加载超出卸载前基线”调整，设为 0 关闭这一额外条件及其跟踪保护，恢复原重新加载规则。
参考在 activate → slowback 时保存；slowback → recover 不改写。同一恢复周期再次卸载时仅允许参考升高，防止基线因下冲而变低后降低重新加载门槛。恢复到 idle、停用或重新初始化时清除参考。
仅凭相对谷值的增加量容易把松手后的深下冲回弹当成新按压；即使 recover 基线已经降低，input 尚未超过原释放参考及余量时也不重新激活。
启用保护时，recover 中达到上升速度门限且 input 已越过卸载前参考基线，才暂停跟踪，等待幅度与连续帧确认；参考以下的快速回弹继续快速跟踪。
余量默认300使用乘增益后的count，调高可抑制越过参考的小幅回弹，也会延迟或漏掉较轻的重新按压。若回弹与真实按压的单通道波形相同，仅靠本规则无法完全区分，需结合实物操作验证。
确认中断后允许恢复跟踪。进入状态的那一帧立即使用新状态的输出规则，slowback 当帧 Signal 就为零。

slowback 提前恢复的差值定义为 `abs(input − baseline) / abs(baseline) × 100%`，默认 10%，连续确认默认 3 帧，两项均可调。
例如 baseline 为 10000，input 位于 9000～11000 内连续达标即可提前进入 recover；基线为零时只接受 input 也为零，不做除零运算。
进入 slowback 的当帧不计入等待或提前恢复确认，从下一有效采样开始计数；不达标就清空连续计数。进入 recover 的当帧仍保留原基线，从下一帧开始快速跟踪。
重新加载判定优先；速度达到重新加载上升门限时暂停提前恢复确认，避免新按压尚未确认就被快速基线吸收。最长等待仍是独立的兜底条件。

最长等待 300 帧按传感器实际采样计数，100 FPS 时约 3 秒，不按 GUI 刷新次数计数；相对差值先达标则不必等满 300 帧。
alpha 0.1 对稳定输入在 100 帧后剩余误差约为初始误差的 0.0027%；仍需满足恢复差值和稳定性条件，不强制满 100 帧转 idle。

## 配置与重置

### 空闲负向扰动与释放下冲

状态机版本2将原 negative recovery 拆分为两个公开状态：
- IDLE_NEGATIVE（编号4，空闲负向扰动）：idle中出现明显下沉，未确认本通道按压。不能仅凭本通道Raw归因为其它通道干扰。
- RELEASE_UNDERSHOOT（编号5，释放下冲）：本通道激活后释放，或同轮恢复期间再次出现明显下冲。

两个状态Signal均为0，只描述负向下降阶段。下沉进入差值默认200 count，连续确认默认3帧。
idle首个下沉候选起暂停基线跟随，保住原零点。恢复期间重入需同时满足：相对本地平台新下降超过200 count、低于原参考超过200 count、速度低于负的稳定速度门槛，并连续确认。
处于旧零点下方本身不会再次进入负向状态；静态低平台与缓慢漂移留在recover。

下降速度减弱至不低于负的稳定速度门槛，或转为回升，连续满足recover_frames（默认5帧）后退出：
- 已接近原参考且速度稳定：直接idle，保留原参考为基线并结束恢复周期。
- 释放下冲后仍有明显正向回弹：slowback。
- 其余情况：recover。

recover中工作基线按recover_alpha跟随，但release_reference固定保留，不作为第二套隐藏状态。
原零点附近连续稳定可回idle；偏离原零点的残余平台仍需原有5秒连续稳定及整体幅度范围保护才提交新零点。
这段等待属于recover，不再占用负向状态。普通释放的快速恢复规则保留。
首次activate、idle负向扰动建立对应恢复来源；重新activate标记新的释放周期，idle、禁用及重置清除来源。

经历负向形变后的再按压保护继续使用negative_press_margin、negative_press_rate、negative_press_frames；
移入slowback/recover后仍使用这组保护，不因状态名字改变而放松。
本轮没有负向形变的普通再加载使用reload参数及相对谷值增加量。
通道覆盖仅替换增量余量和确认帧数，首次idle激活不变，速度条件仍须通过。
快回弹可能与真实按压具有相同轨迹，需结合实物验证，不将稳定高平台无条件视为释放。

重新初始化、采样缺口、断流、参数和增益改变清除恢复来源、确认计数及旧参考。
运行时真实状态仅由_Channel.commit_state()提交；不改变固件状态、协议或原始采样。


### 参数保存与重置

公共参数按用途分组，可展开或收起；输入框仅显示数字，单位在标签旁。
修改草稿后点击“确认生效并保存”：先校验，原子写入sensor_display_config.json，成功后应用并重新初始化。
保存失败保留旧运行参数、旧配置文件及草稿；没有点击确认的草稿不生效、不保存。
释放差值须小于激活差值，recover alpha不能小于idle alpha。
参数、Raw增益、连接、采样缺口或时间异常引起重新初始化；手动重置跳过旧缓存。
实验运行状态和基线不跨会话保存，重启后请保持释放完成初始化。

### 通道参数覆盖

默认所有通道使用公共参数。勾选“覆盖公共参数”后填写增益后的增量余量及确认帧数。
覆盖统一作用于两种负向状态及slowback/recover，首次idle激活不变；速度要求仍使用对应公共值。
负向恢复周期使用负向再按参数，普通再加载使用reload参数及相对谷值增加量。
未勾选时数值输入隐藏，悬停可查看各入口实际公共参数；勾选时复制公共恢复余量及reload_frames。
Ctrl/Shift多选单元格可批量填写或恢复公共参数；草稿统一确认保存后生效并重新初始化。
覆盖设置随JSON保存，重启恢复。

### 派生状态日志与验证

串口日志保留host_state_config及host_state_machine事件，包含实验输入、工作基线、Signal、速度、真实状态和初始化代数。
pressure_rate在各状态逐采样计算；decision_rate保留活动与恢复阶段参与判定的速度，idle为无效值。
activation_events只在进入activate时记录当帧完整判据，退出后最近激活原因保留，重置时清除。
release_reference是保留的原零点，recovery_source标记本轮来源，不替代真实state。
这些事件不计入采样数；仅kind=frame且type为debug/signal的记录算传感器采样。
tools/test_host_state_machine.py验证通道隔离、来源拆分、各出口、稳定平台、新下冲、再按压保护、帧数覆盖及采样重置。
tools/test_host_state_ui.py验证显示、配置保存与失败保护、重启恢复、布局及独立固件数据；不打开真实串口或驱动鼠标。
