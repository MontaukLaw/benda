# 相对触摸板试验

## 圆形应用表盘

选中图标显示淡蓝色柔光亮边并保持完整亮度，其余图标默认以50%不透明度显示。拖动和惯性过程中，高亮随最近的图标平滑切换；吸附过程中锁定目标图标。右侧“中心高亮”可调整边缘高亮强度、非中心图标不透明度和高亮过渡时间，自动保存并在下次启动恢复；高亮强度设为0可关闭亮边，不透明度设为100可取消其他图标的调暗。

左侧“圆形表盘”、右侧“表盘设置”提供蜂窝应用盘。共有100个固定编号的模拟应用，按10×10周期网格排列，可水平、垂直无限循环拖动。视窗只显示落在圆形区域内的图标；每个编号都可以滚动到中心。

- 传感器操作：在“触摸板”页启用，上位机 Signal 模式等待基线初始化，Raw 参考模式先采集松手参考，再回到表盘。直接消费相对手势，不需要接管系统鼠标；表盘速度独立于触摸板的光标灵敏度。
- 无硬件预览：用鼠标左键拖动圆内图标。移动的是整片应用盘，不改变单个应用在蜂窝中的排列；轻点一个图标将其居中。图标仅用于模拟，不启动真实应用。
- 松手：按末段运动速度惯性滑行，再吸附最近的图标。吸附默认500毫秒，时长从惯性结束时开始计算。速度很低或惯性关闭时直接吸附；停止移动一段时间后松手不会再甩动。
- 上位机 Signal 模式中，激活通道不足两路或不再有物理相邻对时，立即停止传感器位移并直接吸附最近图标，不继续惯性滑行。后续释放帧不会取消或重启吸附；再次落指仍可接管动画。
- 接管：拖动、滑行和吸附中再次触摸可立即接管。切换页面、断流、采集参考或按Esc时终止当前手势，避免把通信中断当作一次甩动。
- 图标：仅选中项放大，其余统一保持小尺寸。拖动与惯性时选中最近项，轻点或自动吸附时锁定目标；切换后旧项立即缩小，新项平滑放大。右侧“表盘设置 → 图标布局”可调节选中直径、未选中直径、图标间距、选中放大过渡时间及编号显示。默认直径分别为84和38像素；沿用旧配置中的大、小直径，中档直径和区域半径不再使用。
- 调节：滑动速度、方向、点击容差、惯性强度、衰减时间、最大距离、最高速度、最长时间、停止速度和吸附时长均可调。像素参数指缩放前的表盘逻辑坐标。输入框仅显示数字，单位在旁边标签中。

全部表盘参数自动保存到既有`sensor_display_config.json`的`watch_face`字段，重新启动自动恢复；保存采用原有400毫秒延迟与临时文件替换。可用“恢复默认参数”重置配置，“回到应用001”重新居中。图标编号和布局固定，当前滑动偏移及正在进行的动画不跨启动恢复。

这版用于验证20通道阵列能否提供连续、准确的鼠标移动。原有阵列质心页面和固件不变。

## 使用

1. 运行上位机Python源码，连接20通道设备，选择Debug输出。
2. 左侧选择“触摸板光标”，右侧选择“触摸板”，勾选“启用相对触摸板试验”。
3. 默认来源为 **上位机 Signal 质心**：保持释放，等待“基线与状态机”的初始化完成即可滑动，不需要额外采集参考。使用全部20路上位机 Signal 加权质心，经 One Euro 位置滤波后，`dx/dy = 连续质心差 × 灵敏度`，驱动触摸板画布；不会再次乘增益或扣参考。面板显示当前质心、格单位差值及像素位移。
   仅当至少一对 activate 通道在实际阵列中上下左右相邻时更新质心。仅1路、0路或所有激活通道互不相邻时保留最后质心，显示“保持”，位移为0。对角线不算相邻，编号连续也不一定相邻，例如CH3–CH4不相邻。条件恢复后重新确认接触并锚定，不补发中断期间的位移。
   若选择 **Raw 减松手参考**，完全松手，点击“采集松手参考”。需要连续1秒、至少32帧的稳定Raw，且固件20路均为IDLE、Signal低于阈值的一半。
   旁边的“强制采集”跳过通道状态及Signal释放门槛，可在普通采集等待时直接切换；仍要求有效、连续1秒、至少32帧的稳定20路Raw。适用于Raw观察模式没有上传通道状态等情况，采集前请自行确认松手。状态和日志标记为强制采集；取消、停用或参考失效会清除该采集模式。
   UART Type 0x16的Raw观察帧带`raw_only`标记，参考就绪后按`max(0, Raw × 通道增益 - 松手参考)`判断接触；至少一通道达到接触阈值（默认100 count）并持续30毫秒后锚定，后续质心变化驱动光标。已接触时使用阈值的60%保持接触。整体卸载检测在阈值和位置滤波之前停止位移，残留响应仍高于阈值也不继续跟踪；新的明显加载后重新确认接触并锚定。无需Signal或通道状态，不改写固件通道状态；普通Debug仍按原有Signal及真实状态门控。两种数据模式切换、断流或序号缺口会重新锚定，避免跨断点跳动。
   按钮下方的独立状态区显示开始提示、进度条、有效采样秒数和帧数。等待时会说明尚未空闲的通道、Signal过高、Raw不稳定或缺少Debug数据；只有成功后才显示100%和绿色“采集完成”，结果持续保留。采集中可点击“取消采集”，断流会清除进度并在数据恢复后自动重新采集。
4. 基线初始化或 Raw 参考采集完成后滑动。虚拟画布是1920×1080，抬手后光标保留位置，再落指重新锚定后可继续划动。原阵列质心页保持其自己的来源选择；触摸板的新来源与波形和柱状图来源独立。
5. 如需试用系统鼠标，勾选“控制系统鼠标”。窗口激活时生效；Esc或应用失去激活会取消该开关。第一版只支持移动，不包含点击、拖动、多指或滚动手势。

灵敏度默认300像素/格，接触阈值默认100 count，静止滤波截止频率默认2.5 Hz。输入框只填数字。系统鼠标通过Qt桌面坐标移动，高DPI下对应逻辑像素，不是USB HID计数；当前不向外部屏幕设备发送协议。

### 整体释放阈值调整

“触摸板 → 整体卸载检测（当前输入来源）”提供两个独立输入，作用于上位机 Signal 或 Raw 观察模式，均自动保存、立即生效，并记录在touchpad日志的settings中；调整会中断当前轨迹、清除滤波和小数尾量，Raw 模式保留松手参考。已经确认释放的停止锁存也会保留，直到新的明显加载后再锚定。旧配置没有这两项时沿用默认值，无需迁移配置文件。

- **卸载下降阈值（%）**：默认25，可输入5～80。最近80毫秒内的下降量相对于此前总Signal或Raw差值的比例；调低可更早停止，过低可能中断正常滑动。
- **单路回升容差（下降量 %）**：默认0，可输入0～20。允许某一路在整体卸载时短暂回升，容差取本路6倍噪声与“整体下降量 × 此比例”中的较大值；总回升仍必须小于整体下降量的20%。调高可避免小路回弹延后释放，过高可能把正常空间转移误判为卸载。

可以先试下降阈值20、回升容差5；若仍回勾，再将下降阈值降至15。若正常滑动被截断，提高下降阈值或降低回升容差。两项作用于上位机 Signal 及 Raw 观察模式，普通 Debug 的原状态门控保留，独立于接触阈值；输入框内只显示数字，百分号在旁边标签中。

## 数据路径

上位机 Signal 来源：每个有效 Raw 采样先经过实验状态机，使用同帧的真实实验状态检查相邻 activate 对，满足后才用该帧20路 Signal 做全部通道加权质心，坐标为各通道 `(列+0.5, 行+0.5)`。相邻对缺失或总 Signal 为0时不计算位置。没有将实验状态码冒充固件状态，也不将原始固件 Signal 作为缺失时的替代。只消费一次 Raw 增益，之后使用现有位置滤波及接触位移逻辑。相邻对失效时显示坐标保持，运动滤波及小数余量清除；真正断流、无效数据、来源切换、baseline 初始化代数改变及硬件参数变化会清除旧位置。新触摸从零位移重新锚定。
日志 `source=host_signal_centroid`、`algorithm_input=host_signal`，附带同帧 Signal、`host_state`、`host_active_channels`、`host_adjacent_pairs`、`host_generation`、`centroid_dx/dy`（格）、`dx/dy`（像素）、滤波前后质心和`centroid_held`，便于按序号与状态机日志对齐。相邻对缺失的停止原因是`no_adjacent_activate_pair`。单路噪声门限默认2 count；整体卸载检测检查当前 Signal，不等待位置滤波回落。

以下是保留的 Raw 参考路径：

- 柱状图与触摸板共用20路Raw增益，算法输入为`Raw × 通道增益`，不受柱状图当前显示Signal或Raw、柱高上限及自动量程影响。增益为0时该路Raw权重为0；接收样本和原始串口日志保留原值。
- 松手时分别采集20路增益后Raw的平均值作为参考，并以同口径测量噪声。普通采集与强制采集均使用增益后的输入，稳定性检查也采用该口径。
- 位置权重来自每通道的正向Raw差值。接近噪声的权重被连续衰减；没有用全阵列均值代替每路背景，也没有用标准差本身定位。
- 三帧中值去除单帧尖峰，然后用全部20通道质心和One Euro滤波估计位置。全部通道参与可避免最强2×2硬切换引起的跳变。
- Signal与真实固件状态只用于接触判断，FLOATING的Signal锁定不锁定Raw位置。没有新增或改写固件通道状态。
- 同一次连续有效接触的位置差乘以固定灵敏度，得到浮点dx/dy。系统光标输出整数时保留小数余量。
- 接触初始确认30毫秒，只建立参考、不跳光标。抬指、无效数据、超过150毫秒的断流、队列序号缺口和大幅位置突变会中断轨迹。
- 抬指时检查最近80毫秒内的增益后Raw差值，比较间隔至少25毫秒。Raw模式的下降比例和单路回升容差使用上述可调阈值，并保留噪声及总回升限制；默认25、0沿用原有判定。普通Debug模式仍使用25%下降门槛和恢复权重占主导的真实状态条件。默认单路噪声门槛可避免不等增益下的正常空间转移被误判为卸载。
- 确认释放后停止输出，清除中值窗、位置滤波和系统鼠标的小数余量。Raw模式在残留高于阈值或后来低于阈值时均保留停止锁存；出现超过噪声及幅度门槛的新加载后重新确认接触，第一帧只锚定，不补发释放尾段位移。日志记录停止原因、活动权重比例（Raw模式为null）、`raw_gains`和`algorithm_input`，便于复核。
- 512帧有界队列保证GUI每次刷新消费所有新采样；超过150毫秒的旧帧不补发到光标。

Raw 参考在使用期间固定，避免把手指信号吸收到背景。重新连接、固件重新校准、修改三参数、回读发现硬件参数改变或修改柱状图Raw增益时，Raw 模式必须重新采集；上位机 Signal 模式等待实验 baseline 重新初始化。增益变化会中止正在进行的采集与手势、关闭鼠标控制并清除旧参考；仅改变柱状图显示源、视角或量程不会清除参考。参考、启用和鼠标控制开关不跨启动保存，触摸板来源及数值设置会保存；Raw增益统一保存于柱状图配置并在启动时同步到算法。

## 滑动一致性测试

左侧显示区新增“滑动测试”Tab。连接20通道传感器、使用含Raw的Debug输出，等待上位机状态机初始化完成；触摸板来源选择连续位置权重或上位机Signal，然后点击“开始测试”。测试临时开启跟踪，停止系统鼠标控制，结束后恢复原来的跟踪开关。连续模式在首段松手倒计时结束后还会等待位置参考就绪，最长30秒；超时中止并保存已有数据，避免漏记第一趟。

默认横向5次、纵向5次：先完全松手3秒；每次准备3秒，在2秒窗口中横向左到右或纵向上到下滑动一次，再抬指观察3秒。固定实际起终点和力度，抬指返回起点，避免贴着返回被误记成正向滑动。次数、时间、实际距离、力度和备注可修改并自动保存；距离未知填0。计次仅代表人工操作提示，不以质心、activate数量或接触状态判断是否做完一次动作。

结束后自动生成 `recordings/slide_tests/slide_test_<时间戳>_<标识>.zip`，页面显示完整路径，并提供“打开数据目录”。直接提供ZIP分析即可。内部 `records.jsonl` 包含测试时间段的原始RX/TX、全部解析帧、逐帧上位机input/baseline/Signal/状态/速度/激活原因、质心和dx/dy，以及带方向、次数和采样时钟的阶段起止标记。`manifest.json` 保存参数、Raw增益、三参数回读、通道布局、测试设置、帧计数、采样间隔、日志丢失数及SHA256。Raw保持原值，上位机输入已按增益及低通处理；两者均可复核。

归档独立于滚动日志保留范围，ZIP生成在后台进行；源JSONL及清单也保留。用户停止、断线、采样中断、计时中断或运行参数变化时保存部分数据，并标明中止原因；存在缺失数据不会标成完整成功。写盘失败显示错误和已写入文件位置。窗口关闭会等待归档完成。

## 连续位置权重与8毫米物理阵列

右侧“触摸板 → 触摸板输入来源”增加“连续位置权重（推荐）”。旧Signal模式保留及原配置来源不变，第一次试用需手动切换。采用当前通道映射：

```text
CH0  CH4  CH8   CH12  CH16
CH1  CH5  CH9   CH13  CH17
CH2  CH6  CH10  CH14  CH18
CH3  CH7  CH11  CH15  CH19
```

横纵中心间距均8毫米，传感器直径5毫米。CH0中心设为毫米原点，右为X正方向、下为Y正方向，中心覆盖32×24毫米，包含传感器半径的外包络37×29毫米。原来的格坐标和像素灵敏度保留：1格=8毫米，400像素/格相当于50像素/毫米。毫米位置是传感器几何质心换算，尚未标定为手指真实位置；传感器直径只作为几何信息记录，不据此硬截断压力分布。

## 残留位置权重的平滑衰减

连续模式增加“平滑抑制非activate通道的残留权重”，默认开启。它只消费同帧实验状态，给位置权重乘一个20路连续系数，不新增或改写任何通道状态。activate时系数趋向1；slowback、recover及idle时趋向可配置的保留比例。idle不重新恢复旧残留；新activate后平滑恢复。禁用通道仍没有位置权重。

- 残留衰减时间常数：默认80毫秒，可调20～500。偏离目标的部分经过一个时间常数剩约37%，三个时间常数剩约5%，不是80毫秒到点突然归零。
- 重新加载恢复时间常数：默认20毫秒，可调10～200。
- 残留最大衰减比例：默认60%，可调0～100。默认非activate最终保留40%的连续权重；100趋近完全抑制，0与关闭开关一样恢复上一版连续权重。

系数按每个采样的实际时间差指数更新，与采样率无关。丢帧、断流、来源或增益改变及状态机重新初始化时，系数与位置参考一起清除。相邻激活条件失效或整体卸载时保持显示位置、清除运动尾量；权重系数继续平滑变化，新接触从零位移锚定。整体卸载和新加载判定始终采用衰减前的真实连续差值，不把人为衰减当作释放。

三个数值和开关立即生效并自动保存，改动会取消当前手势、重新等待松手参考。面板支持滚动，较小窗口也可以查看全部参数和状态。touchpad日志增加`position_unattenuated_weights`、`position_factors`、衰减后的`position_weights`及`position_weight_model`，模型为`state_smoothed_v1`或关闭时的`continuous_v1`；测试清单和运行参数变更检测包含全部新参数。
