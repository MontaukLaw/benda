# 手动回弹观察

> 手动回弹观察属于独立诊断功能，不是电机压力—行程学习或传感器K表标定。当前功能分工见[总入口](../../CURRENT_SYSTEM_CN.md)，新标定见[自动标定](../../HIGH_FORCE_CALIBRATION_CN.md)。

在源码版上位机右侧选择“手动回弹观察”Tab。接通电机CAN、压力计和传感器Debug串口，确认释放点。当前ZDT使用压力反馈页的共享参数和已核验学习表；无有效学习表时保守寻压，旧压力－位置表仅供采集位置参考。目标压力按钮沿用监控控制器的可用档位；灰色表示当前不可执行。

1. 选择目标压力，例如2 N。ZDT复用监控页的快速接近与压力闭环到位逻辑，界面同时显示目标与压力计实测值；到位后的手动观察不执行恒力补偿。旧PD42S1配置仍沿用原查表控制，不能混用两种电机的参数和记录单位。
2. 自行保持需要的时间。页面显示下压发令后经过时间、接触持续时间和到位保持时间。
3. 点击“释放 / 回到标定出发点”。日志记录释放前实测力、已观测峰值及上述时长，并列出CH4～CH7释放时的真实状态。
4. 查看每通道的真实状态、冻结基线参考、Raw及偏差。“回IDLE / s”和“Raw返回 / s”会分别填入结果。

## 时间口径

- 下压/释放时间起点是控制器向驱动器提交运动的时刻；只有驱动器返回接受结果才建立记录，不使用按钮点击时间。
- 接触时间起点是下压后首次观测到有效压力计读数大于0.05 N；到位保持时间从控制器完成下压流程时起算。压力下降或松弛期间不会自动修改电机位置。
- 通道回弹计时从释放发令开始，包含电机卸载行程。日志会另外标出电机回到释放位置的时刻。
- “回IDLE”只认固件真实IDLE（状态0），不会把SLOW_BACK、WAIT_STABLE、RECOVER提前算作IDLE。释放时不是FLOATING的通道会记录真实起始状态。
- “Raw返回”使用与Baseline同量纲的Raw，参考为本轮首次观测到按压冻结时的Baseline。这个参考在恢复过程中保持不变，不能被移动后的Baseline替换。
- 默认Raw需进入原参考±2 counts并连续保持0.5秒。记录首次进入的时间，并在日志标注完成连续确认；开始前可调整容差和确认时长。
- 首次IDLE与Raw返回是两个独立终点：基线重建可能令通道进入IDLE，但Raw仍无法回到原基线。此时保持“未返回”，不会强行记为零。
- 时间来自上位机收到的样本和20 ms轮询，是观测时间，不代表硬件毫秒级事件时间。重复帧不用于稳定确认；超过0.25秒的间断会重置Raw确认并标记时间不确定，超过1秒无新帧则中断本轮。

## 日志与中断

每次观察的事件自动保存到`manual_rebound_observations/manual_rebound_*.jsonl`，页底显示完整路径，也可点击“另存日志”保存屏幕文本。

“结束本轮观察”仅结束已经释放后的计时，不发送电机命令。“紧急停止电机”复用原紧停操作。下一次按压、重新校准、断连或窗口关闭时，上一轮未完成的通道以“未观测到返回”保留，不能当作已恢复。观察没有自动超时卸载或自动开始下一轮。

所有状态均为固件上报，新页不改写通道状态、Baseline或Raw。新功能无需重刷固件；源码版重新启动后加载。自动测试与界面检查使用模拟接口，未执行实际电机动作。
