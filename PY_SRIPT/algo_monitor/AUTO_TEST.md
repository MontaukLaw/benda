# 上位机电机自动测试

> 历史PD42S1位置扫描测试说明，保留当时流程和数据定义；不是现行ZDT压力反馈学习或1～30 N传感器自动标定。当前操作见[压力反馈控制](../../PRESSURE_FEEDBACK_CONTROL_CN.md)和[自动标定](../../HIGH_FORCE_CALIBRATION_CN.md)，不能把此处编码器扫描、Raw量程阈值或连接失效规则套到新流程。

## 坐标与数据定义

- 电机“下压”为编码器位置减小，“抬升”为编码器位置增大。
- 自动测试记录的是本次 CAN 连接期间的逻辑零点，不修改电机内部原点参数。
- 接触判断只使用 CH4、CH5、CH6、CH7 的 `Signal` 和。
- 最大量程判断只使用 CH4、CH5、CH6、CH7 的 `Raw`，因此寻找最大量程时串口必须处于 `Debug` 输出模式。
- 最大下压角度使用“逻辑零点编码器位置 - 最大量程编码器位置”计算，并转换为角度。
- 断开 CAN 后，本次逻辑零点和最大量程结果立即失效，重新连接后必须再次寻找零点。

## 寻找零点

1. 读取当前编码器位置并作为搜索起点。
2. 等待新的传感器帧，连续检查三帧 CH4～CH7 的 `Signal` 和。
3. 如果三帧的和值都大于接触阈值，则记录当前位置为逻辑零点。
4. 如果尚未接触，则下压 5°，等待电机到位和传感器稳定，然后重复判断。
5. 找到零点后抬升 5°，进入准备状态。
6. 如果达到安全搜索范围、传感器停止更新或电机到位超时，则终止搜索，并尽量返回搜索起点。

## 寻找最大量程

1. 必须先在本次 CAN 连接期间成功寻找逻辑零点。
2. 从当前位置开始检查 CH4～CH7 的 `Raw`。
3. 如果连续三帧中任意通道都达到或超过 60000，则记录当前编码器位置和相对零点的最大下压角度。
4. 如果尚未达到上限，则每次下压 10°，等待电机到位和传感器稳定，然后重复判断。
5. 找到最大量程后自动返回逻辑零点上方 5° 的准备位，避免传感器持续承受最大压力。
6. 如果达到安全搜索范围、传感器停止更新或电机到位超时，则终止搜索，并尽量返回准备位。

## 停止与超时

- 两个自动测试都在后台工作线程中执行，不阻塞 Qt 界面。
- “停止”按钮会设置停止标志；当前同步 CAN 请求返回后，流程执行刹车停止，不继续下一个步进。
- 每次运动后使用 `0x2C` 读取运行状态，并使用 `0x2A` 读取实际位置；只有电机报告停止/任务完成、已经产生有效位移且实际位置连续稳定三次，才认为本次运动结束。
- 理论目标与实际位置的误差只用于日志诊断，不再作为运动失败条件；下一步始终从实际停止位置继续计算，避免位置误差逐步累积。
- 每次等待电机停止和等待传感器新帧都有独立超时，避免自动测试永久卡住；过载、堵转和欠压状态会立即终止流程。
- CAN 日志记录自动测试开始、每步进度、触发值、最终位置、失败原因和返回安全位置失败信息。

## 随机按压自动测试

必须先完成“寻找零点”和“寻找最大量程”。点击“开始自动测试”后，上位机以接触零点为运动基准执行 10 轮测试：

1. 从零点随机选择一个整数下压角度，默认范围为 10°～`min(已测最大量程, 100°)`。
2. 到位后随机保持 1～5 秒。
3. 电机返回零点，并继续观察释放后的通道状态，默认最多观察 15 秒。
4. CH4～CH7 分别检查是否按顺序出现 `RISING → FALLING → SLOW_BACK`。
5. 统计 `SLOW_BACK` 状态内 Signal 非零的帧数；只有出现过 `SLOW_BACK` 且所有对应帧的 Signal 都为 0 才判定通过。
6. 若释放后没有在观察期限内回到 `IDLE`，本轮标记 `TIMEOUT`，随后继续下一轮，避免测试永久卡住。

“中途停止测试”会设置停止事件并制动电机。测试数据保存在 `automatic_tests`：

- `random_press_detail_时间戳.csv`：逐帧记录测试轮次、阶段、随机角度、Raw、Baseline、Signal、状态、Fast/Slow K 和 Noise。V8 已停止上传 Raw/Signal K 与旧归一化 K，因此自动测试文件也不再包含这些字段。
- `random_press_summary_时间戳.csv`：记录每轮角度、保持时间、状态顺序判定、回到 IDLE 的结果和 `SLOW_BACK` Signal 判定。

随机种子同时写入详细数据和 CAN 日志，用于复现相同的角度与保持时间序列。相关参数位于 `motor_control_config.json`，键名以 `random_test_` 开头。

## 重复精度测试

- 快速连续模式在下压到参考位置后，要求 CH4～CH7 中达到界面设定数量的通道进入 `FLOATING`，并连续满足 `auto_confirmation_frames` 帧；随后记录该帧四个通道的 Signal 值及其总和。未进入 `FLOATING` 的其他通道仍包含在 Signal 和中。
- 快速连续模式的预压稳定窗口与正式测量使用同一个可配置的 FLOATING 通道数。预压最近3个同停点有效 Signal 和的相对极差达到设定阈值后，进入设定轮数的正式测试；未满足时最多执行设定的预压轮数。
- 每轮等待足够通道进入 `FLOATING` 都有可配置的秒级超时；超时后本轮不记录结果，但会正常抬升并继续下一轮，不再终止整次测试。达到条件后先记录当帧 Signal，再按配置继续保持压力，默认2秒后抬升。
- 点击“快速连续测试”时，界面会立即把测试档位、FLOATING通道数、预压相对极差阈值、正式轮次、预压最大轮次、FLOATING超时和FLOATING后保持时间写入 `motor_control_config.json`，本次后台测试使用点击瞬间冻结的参数。
- 正式结果除平均值、最小值、最大值、极差和相对极差外，同时计算 Signal 和的样本标准差，采用 `n-1` 作为分母；只有一个有效结果时标准差记为0。
- 正式阶段仍要求实际下压位置与锁定参考完全相同。如果同一个非零误差停点连续出现3次，且下压、回程都在位置容差内，则认为实际可达位置发生稳定迁移：废弃已经采集的旧正式结果，重新执行预压判稳，并从第1个正式结果重新采集。一次测试最多自动重锁3次，超过后明确终止，避免几十轮无意义空跑；最终 CSV 只包含最后一次锁定位置下的正式结果。
- 完全恢复模式仍要求 CH4～CH7 全部进入 `FLOATING` 才记录结果，抬升后也仍需等待四个通道全部回到 `IDLE`。

## 可读写参数

以下参数保存在 `motor_control_config.json`。快速连续测试参数可直接在界面修改，并在点击“快速连续测试”时立即保存和生效；其余未提供界面入口的参数应在 App 关闭时修改，重新启动后生效：

| JSON 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `move_count_units` | 1 | 手动运动档位，每档对应电机轴约28.8° |
| `speed_level` | 5 | 速度档位，每档约4.8 RPM |
| `acceleration` | 100 | 加减速度，范围0～200 r/s²；0表示直接启动 |
| `auto_zero_step_deg` | 5.0 | 寻找零点时的单次下压角度 |
| `auto_max_step_deg` | 10.0 | 寻找最大量程时的单次下压角度 |
| `auto_contact_signal_threshold` | 0 | CH4～CH7 Signal 和的接触阈值，判断条件为大于该值 |
| `auto_raw_limit` | 60000 | 任一 CH4～CH7 Raw 的最大量程触发值 |
| `auto_ready_lift_deg` | 5.0 | 找到零点或完成量程测试后的准备位抬升角度 |
| `auto_sensor_settle_seconds` | 0.3 | 电机到位后等待传感器稳定的时间 |
| `auto_sensor_frame_timeout_seconds` | 1.0 | 等待传感器新帧的超时 |
| `auto_motor_position_timeout_seconds` | 8.0 | 等待电机到位的超时 |
| `auto_max_search_travel_deg` | 720.0 | 相对搜索起点/逻辑零点允许的最大下压范围 |
| `auto_confirmation_frames` | 3 | 接触或满量程条件连续成立的帧数 |
| `random_test_rounds` | 10 | 随机按压轮数 |
| `random_test_min_angle_deg` | 10 | 随机下压最小角度 |
| `random_test_max_angle_deg` | 100 | 随机下压最大角度，仍受实测最大量程限制 |
| `random_test_hold_min_seconds` | 1.0 | 到位后随机保持时间下限 |
| `random_test_hold_max_seconds` | 5.0 | 到位后随机保持时间上限 |
| `random_test_release_observe_seconds` | 15.0 | 每轮回零后的最长状态观察时间 |
| `repeatability_count_units` | 1 | 重复精度测试行程档位，每档对应电机轴约28.8° |
| `rapid_floating_channel_count` | 1 | 快速测试每轮完成采样所需的 FLOATING 通道数，范围1～4 |
| `rapid_precondition_relative_span_percent_max` | 0.5 | 最近3个有效预压 Signal 和允许的最大相对极差，单位% |
| `rapid_formal_rounds` | 10 | 快速连续正式测试的有效结果轮数 |
| `rapid_precondition_max_rounds` | 10 | 快速连续正式测试前允许的最大预压轮数，最小为3 |
| `rapid_floating_timeout_seconds` | 20.0 | 每轮等待足够通道进入 FLOATING 的最长秒数；超时后抬升并继续下一轮 |
| `rapid_floating_hold_seconds` | 2.0 | 达到 FLOATING 条件并记录 Signal 后继续保持压力的秒数 |

## 尚待真机验证

- Signal 和以 `> 0` 判断接触是否会被实际零点噪声误触发。
- 5° 和 10° 步进是否适合当前丝杆/压头机械传动比。
- 0.3 秒稳定等待是否足以覆盖电机停稳和传感器响应时间。
- Raw 达到 60000 后回准备位的运动方向、角度和机械安全性。
- 720° 安全搜索范围是否应根据实际机构进一步缩小。
- `0x2C` 在当前驱动器固件的闭环相对位置模式下是否稳定返回“正在运行/任务完成”。
