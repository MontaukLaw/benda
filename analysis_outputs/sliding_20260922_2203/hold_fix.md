# 已实现红点消失时的位置锁定

收到新的有效性规则后，上位机改为：

1. 已有有效红点时，第一次低于阈值、全零或进入释放尾段，冻结最后实际显示的位置100毫秒。
2. 冻结期间不把残留Signal计算出来的坐标送入X/Y滤波，也不继续外推位置。
3. 100毫秒内恢复有效信号，沿用冻结的滤波位置平滑续接；复位速度估计，避免把缺口内的位移当成瞬时高速运动。
4. 持续失效达到100毫秒，则原地隐藏并清除位置滤波历史；再按压从新位置显示。
5. 无有效历史时，低于阈值仍不显示。无效数据、断流判定及设置新阈值仍清理历史。

冻结期限由采样单调时钟计算，GUI也检查到期时间；没有下一串口帧时也不会无限冻结。
关闭平滑时依然冻结最后实际显示位置，但恢复后的坐标按“平滑关闭”的设置直接显示原始质心。
原有Signal、Raw、Baseline、通道状态、缩放与阈值设置均保留。

centroid日志新增holding_position、hold_started_at、signal_valid，filter参数含disappear_hold_seconds=0.1。
界面时钟触发的隐藏另记update_reason=hold_timeout，不冒充新的传感器采样。
冻结期间displayed_xy可以非空而signal_valid为false，这是当前授权的短时位置保持，不是低阈值输入重新定位。

离线回放此前固定保存的日志，阈值1000时的9次11～84毫秒信号缺口均成功保持原位，
整个回放560条冻结记录中坐标变化次数为0；具体结果在hold_replay.json。
恢复首帧位移由原先0.59～2.12格降为约0.07～0.34格，这仅评价显示衔接，不代表真实定位精度。

10项滤波测试及GUI集成测试通过，包含全零/弱信号/释放尾段锁定、短缺口续接、超时再按、
关闭平滑仍锁定、无下一帧时自动隐藏，以及日志只记录一次超时事件。
