# 已实现：释放尾段隐藏及阵列缩放

位置滤波参数保持不变；只增加质心显示有效性判断，不改Signal、Baseline或固件通道状态。

- 总Signal降至本次连续触摸峰值的2%以下，且所有仍有Signal的通道均为真实FALLING时，隐藏质心并清空X/Y滤波历史。
- 隐藏期间继续保留原始质心用于日志，不让剩余弱信号继续驱动红点。
- 新的RISING/ACTIVE触摸，或总Signal回升至峰值4%，恢复显示并重新建立峰值，从新位置开始滤波。
- Run没有状态字段时，使用总Signal下降作为辅助证据；隐藏后以明显回升或4%门槛恢复。Run无法像Debug一样核对真实释放状态。
- 全零、无效数据或断流继续清除全部位置显示历史。直接开始的小信号触摸不受固定计数门槛限制。
- 平滑开关关闭时仍执行释放隐藏；缩放操作不会重新计算或推进滤波。

“波形设置 → 阵列质心”新增阵列缩放滑动条：30%～100%，默认70%，居中等比例缩放。
缩放与平滑开关一样保存到sensor_display_config.json。缩放不改变格坐标、Signal权重或定位结果。

centroid日志增加state、release_hidden、touch_peak_signal、release_threshold与scale_percent。
这些字段用于区分释放隐藏与全零、断流，并复核当时的实际显示。
