# 延后FLOATING锁定验证

在本轮峰值超过300 counts时，将最短受力时间从1秒延后至4秒，然后才开始连续300 ms稳定确认。峰值不超过300 counts时仍使用1秒及3帧确认。300 counts是传感器Raw相对激活基线的幅度，不是压力计N值。

这是一段有边界的延迟：没有等待电机发出“到位”命令，也没有更改FLOATING退出阈值。延迟期间Signal继续反映Raw变化，松手仍走原状态机释放路径，下一次按压重新计时。当前名义160/250 Hz下最早约受力后4.3秒锁定；传输快照采样率和空行程会影响映射到按钮启动后的时间。
